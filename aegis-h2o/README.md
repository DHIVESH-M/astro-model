# Aegis H2O — AI + IoT Water Monitoring & Filtration Research Platform

Official technology research blog and project showcase website for project **Aegis H2O**, developed by team **Super Clusters** at **Rathinam Global Deemed-to-be University**.

---

## 🚀 Quick Start Instructions

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Local Development Server**:
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:4321`.

3. **Build Production Distribution**:
   ```bash
   npm run build
   ```

4. **Preview Production Build**:
   ```bash
   npm run preview
   ```

---

## 🛠️ Technology Stack
- **Framework**: Astro.js v4+ with Content Collections
- **Styling**: Modern CSS with CSS custom properties (Variables)
- **Icons**: Lucide SVG Icons
- **Animation**: Anime.js
